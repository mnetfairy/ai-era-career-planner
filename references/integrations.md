# v2.0 生态集成

> 🔒 **2026-11-11 安全整改（v2.3.10）**：本 skill 的能力声明为**无网络出口**
> （manifest 中不声明任何联网能力）。因此本文件**不再提供任何外发/联网的操作指引** ——
> 下列条目全部改为「**由宿主 agent 或用户自行处理**」的说明，本 skill **不执行**、
> **不指导**、也**不代为发起**任何外部请求。
>
> 本 skill 的全部参考资料均为本地静态文件，运行期默认**完全离线**。

## 报告分发（不由此 skill 执行）

- **发送到邮箱**：本 skill **不发送**邮件。需要邮件分发时，请由**宿主 agent** 或
  用户本人完成；本 skill 的职责范围仅到「在对话中输出报告」或「导出到 `./exports/`」。
- **订阅资讯**：本 skill **不订阅**任何内容。职业方向资讯的订阅由用户自行在
  外部渠道设置。
- **实时招聘数据**：本 skill **不联网**检索。需要实时数据时，由宿主 agent 在
  **用户明确要求**的前提下自行检索，并把结果带入对话；本 skill 只负责基于
  本地参考资料完成分析与呈现。

## 长期档案（🔒 仅写入受控目录）

- 本 skill **不写入** `MEMORY.md`，也**不写入**工作区 `memory/` 目录。
- 如用户明确要求保存规划摘要：
  1. 摘要文本**在回复中直接提供给用户**，由用户自行复制到自己的笔记系统；
  2. 如需留存在 skill 自己的目录内，**仅写入 `./exports/tracking/`**
     （见 `references/tracker_system.md` 的保存路径与保留期限规则）。
- 该约定与 manifest 声明的写入边界（仅 `./exports/`）完全一致；
  任何指向 `./exports/` 之外的记忆写入一律不做。

## 多语言支持

英文报告由宿主 agent 在用户要求时按需生成（属对话产出，不涉及额外文件或网络）。

## 重要原则

- **不自动发送**：不自动发送任何报告、资讯或推送
- **不自动订阅**：不自动订阅任何内容
- **不自动记录**：不自动写入任何 memory 或追踪文件
- **不联网**：本 skill 不发起任何网络请求，也不依赖任何在线服务
- **写入边界**：持久化写入只发生在 `./exports/`（含 `./exports/tracking/`）之内
- **用户授权**：任何外部动作都需用户明确授权，且由宿主 agent 执行

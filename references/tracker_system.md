# 职业规划追踪系统

> ⚠️ 本系统为**可选功能**，仅在用户明确要求保留记录或后续跟进时才使用。
> 🔒 2026-11-10 安全整改：追踪记录的写入路径已收敛到 `./exports/tracking/`
> （skill 根目录下的受控导出区），与 frontmatter `permissions.filesystem.write`
> 声明的 `./exports/` 边界完全一致。

## 用户状态文件

保存路径：**固定为 `./exports/tracking/career_tracker_{user_id}.json`**（相对 skill 根目录）。

- 不再支持「用户指定目录」或「当前工作目录」等 skill 目录之外的路径。
- 不写入 `MEMORY.md`、工作区 `memory/`、用户主目录或任何其它位置。
- 若用户希望把追踪记录放到别处，由**用户自行复制**本目录下的文件，skill 不代为写入。

## 追踪原则

- **用户自主控制**：追踪记录的存在与内容完全由用户决定；不默认创建
- **数据最小化**：只保存用户主动提供的字段，不推断、不补充、不外传
- **可删除**：用户可随时要求删除已保存的追踪记录
- **不自动创建**：不默认在用户无明确授权情况下写入任何文件

### 数据最小化清单（只存这些）

| 字段 | 说明 |
|------|------|
| `user_id` | 用户主动提供的标识（昵称/代号），用于文件名 |
| `created_at` / `updated_at` | 追踪记录创建与最后更新时间 |
| `stage` | 用户自述的当前阶段（高中生/大学生/职场转型/深耕期等） |
| `holland` / `mbti` / `anchor` | 测评结果（用户确认过的类型代码） |
| `goals` | 用户主动给出的职业方向与目标 |
| `actions` | 用户主动认领的行动项与完成状态 |
| `notes` | 用户主动提供的复盘备注 |
| `next_followup_at` | 复盘节点日期（7/30/90 天） |

> 不保存：身份证件号、联系方式、住址、财务账号、第三方账号令牌等任何非就业规划必需的敏感信息。

### 保留期限与删除

- **保留期限：默认 90 天**（与「90 天季度复盘」节点对齐）。超过 90 天的追踪记录在下一次运行时提示用户确认是否清理。
- **删除方式**（三选一，用户随时可要求）：
  1. 删除单个用户的追踪文件：告知 skill 用户 ID，由 skill 删除 `./exports/tracking/career_tracker_{user_id}.json`；
  2. 删除全部追踪记录：清空 `./exports/tracking/` 目录下的 `career_tracker_*.json`；
  3. 用户自行在文件系统中删除对应文件（skill 目录内的相对路径 `./exports/tracking/`）。
- 删除后不留副本、不写入其它位置；删除动作会在回复中明确告知用户。

## 追踪节点

- 7天：首次跟进，问候+执行困难
- 30天：月检视，对照目标评估进展
- 90天：季度复盘，决定是否调整方向（同时是默认保留期限到期点）
- 年度：全面回顾，重新生成规划

## 复盘问卷

1. 上次推荐的行动，你做了哪些？
2. 有遇到什么困难吗？
3. 现在对方向还有信心吗？
4. 有没有发现新机会或新想法？
